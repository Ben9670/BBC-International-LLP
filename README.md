# BBC International LLP

This is the main project repository for BBC International LLP.

## Project Structure

- `frontend/`: Contains the frontend code, including pages, assets (CSS, JS, images), and README.
- `backend/`: Contains the backend code, including source files, package.json, and environment files.

## Getting Started

### Frontend
Navigate to the `frontend/` directory and open `pages/Home.html` in a browser.

### Backend
1. Navigate to the `backend/` directory.
2. Run `npm install` to install dependencies.
3. Run `npm start` to start the server.

## Contributing
Please read the README files in respective directories for more details.
